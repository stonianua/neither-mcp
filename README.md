# neither-mcp

Public source mirror for the Neither CLI and MCP server.

## Packages

Published npm packages:

- [`neither`](https://www.npmjs.com/package/neither) — CLI for pushing local docs to decision memory
- [`@neitherai/mcp-server`](https://www.npmjs.com/package/@neitherai/mcp-server) — MCP server for Cursor and other agent IDEs

## Documentation

- CLI: [https://www.neither.online/docs/cli](https://www.neither.online/docs/cli)
- MCP: [https://www.neither.online/docs/mcp](https://www.neither.online/docs/mcp)

## Install

**npm (recommended):**

```bash
npx -y neither@latest --help
npx -y @neitherai/mcp-server@latest
```

**Homebrew tap:** planned — see release notes when available.
